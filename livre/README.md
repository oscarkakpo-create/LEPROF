# Le livre — espace de dépôt

Déposez ici le fichier PDF du livre associé à **LE PROF**.

## Nom attendu

`le-prof.pdf`

La page `livre.html` pointe vers ce chemin : `livre/le-prof.pdf`.

Si vous voulez un autre nom, modifiez le `href` du bouton de téléchargement dans `livre.html`.

## Comment déposer le PDF

1. Allez sur https://github.com/oscarkakpo-create/LEPROF
2. Entrez dans le dossier `livre/`
3. Cliquez **Add file → Upload files**
4. Glissez votre PDF, renommez-le `le-prof.pdf` au besoin
5. Commit

Le fichier sera accessible à : `https://oscarkakpo-create.github.io/LEPROF/livre/le-prof.pdf`

## Limites GitHub

- Fichier individuel : **100 Mo max** (recommandé < 25 Mo pour un téléchargement fluide)
- Au-delà : utiliser Git LFS, ou héberger le PDF sur archive.org / Google Drive et pointer `livre.html` vers l'URL externe
