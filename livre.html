La démarche

Pourquoi "préparer, évaluer, transformer, relire" plutôt que "générer, publier, oublier". La colonne vertébrale pédagogique.

Les méthodes

Les protocoles qui tiennent devant une classe réelle. Comment utiliser l'IA sans qu'elle utilise votre pensée à votre place.

Le poste de travail

Comment l'atelier LE PROF applique concrètement ces principes — et où il refuse de décider à votre place.

Ce que vous y trouverez

Un livre court, utile, à côté de l'atelier.

Pas un manuel exhaustif. Un compagnon : les cadres de pensée, les gestes professionnels, et les repères pour reprendre la main sur ce que l'IA vous rend. Lecture rapide, références pratiques, exemples issus du terrain.

Sommaire indicatif

Au programme

  1. Garder la main — le pacte pédagogique
  2. Préparer : d'une matière brute à une ressource qui fait apprendre
  3. Évaluer : contextualiser, exiger, rendre robuste
  4. Transformer : donner une nouvelle vie aux supports
  5. Relire : la boucle qui fait la différence
  6. L'atelier en pratique — ce que le poste de travail vous apporte

Le sommaire définitif sera celui du PDF.
